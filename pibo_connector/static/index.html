pibo-connector

찾기

서브넷의 .1~.254 를 훑는다. 15대면 보통 3~8초.

점호

기대 SN 목록 편집
8자리 SN 만 골라낸다. 줄바꿈·쉼표·공백 아무거나 써도 된다.

목록

기종 SN 이름 IP OS_VERSION 온도 상태 마지막 확인

아직 찾은 로봇이 없다. [찾기] 를 눌러라.

코드

⚠ 실행하면 로봇의 tools · classify · llama-server 가 멈춘다. LLM 코드는 Dialog.start_llm 부터 할 것. IDE 의 출력창은 전역이라 교사 브라우저에도 같이 찍히고, 누가 IDE 에서 Run 을 누르면 이 코드가 죽는다.

동시 실행: 무거운 import 를 먼저 끝내게 해두고 전부 준비되면 UDP 트리거로 동시에 푼다. 코드를 # --- GO --- 한 줄로 나누면 위가 준비, 아래가 본편이다. 공유기가 브로드캐스트를 막으면 트리거가 안 가고 [timeout] 으로 끝난다.

출력

실행하면 로봇별 마지막 줄이 여기에 뜬다. 줄을 누르면 전체 로그가 펼쳐진다.
